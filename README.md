# AI Powered Finance Tracker

A responsive finance dashboard for managing income, tracking expenses, and getting AI-inspired spending insights using a JavaScript frontend and Express backend.

## Features

- Income and expense tracking
- Interactive dashboard charts with Chart.js
- AI-inspired insights based on spending behavior
- Responsive layout for desktop and mobile
- Quick transaction entry form
- Persistent JSON-based storage

## Tech Stack

- Node.js
- Express
- Chart.js
- HTML5 / CSS3 / JavaScript

## Run the app locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```

3. Open in the browser:
   ```bash
   http://localhost:3000
   ```

This project is ready to be deployed on platforms like Render, Railway, Vercel (frontend only), or any Node hosting service with Express support.
